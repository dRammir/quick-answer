DeepSeek Quick Answer

Маленький квадрат в правом нижнем углу любого сайта: берёт вопрос из буфера обмена, отправляет его в DeepSeek и показывает номер правильного варианта — для быстрой сверки ответов.

Manifest V3 v1.0.0

Как отвечать

Выберите, откуда брать ответ. Можно переключаться в любой момент.

DeepSeek API

Настройки нужны для режимов «Авто» и «Только API».

Дополнительно: системный промпт
⚠ При смене Base URL Chrome запросит разрешение на доступ к этому домену — без него запросы к API блокируются.

Как пользоваться

  1. 1Скопируйте текст вопроса вместе с вариантами ответов (Ctrl+C).
  2. 2Квадрат находится в правом нижнем углу страницы. Нажмите его или Alt+Shift+D.
  3. 3Рядом появятся только номера: 2 или 2, 4. Номер — это порядок варианта (A = 1, B = 2…).

Номера исчезают сами через 15 секунд. Правый клик по квадрату открывает эти настройки. На chrome:// и в Chrome Web Store квадрата нет — это ограничение браузера.

Приватность

Текст вопроса уходит напрямую в DeepSeek (API или чат). Расширение не ведёт логи, не отправляет данные на сторонние серверы и хранит ключ локально в chrome.storage.local. В режиме вкладки ответы видны в истории вашего аккаунта DeepSeek.

Настройки применяются сразу после сохранения — перезагружать страницы не нужно.
